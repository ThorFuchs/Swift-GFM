# Backend configurations

`MarkdownConfiguration.cmarkDefault` selects the pinned GitHub cmark-gfm parser with no extensions. `.gfm` selects the built-in table, strikethrough, autolink, tag-filter and task-list extensions. Options, extension sets and width can be chosen explicitly; footnotes are an optional C flag. These are backend configurations, not assertions of complete strict CommonMark or GFM specification conformance. The wrapper has no Jekyll profile. See [WRAPPER-API.md](WRAPPER-API.md) for defaults, XML output and qualification limits.
