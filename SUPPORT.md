# Support

Use [GitHub Issues](https://github.com/ThorFuchs/Swift-GFM/issues) for bugs,
questions, and focused feature proposals. Include the SwiftGFM version, Swift
version, operating system, the `MarkdownConfiguration` or CLI command, a minimal
Markdown input, and the expected and actual output or error. Remove
confidential data first.

If the upstream `cmark-gfm` executable at the pinned revision produces the same
output, the behavior comes from the C library; please report it to
[github/cmark-gfm](https://github.com/github/cmark-gfm) instead.

For security issues, follow [SECURITY.md](SECURITY.md). The project is
maintained by @ThorFuchs; no support response time or long-term maintenance
window is promised.
